# Alien: Rogue Incursion

<i>First person action-horror game nominated for <b>Best VR/AR Game</b> @ The Game Awards 2025.</i>

Featuring the Xenomorph as the prominent enemy, the game challenges the player to sneak by or fight through hordes of these "perfect organisms" to escape an abandoned facility. <br /><br />

![preview](https://shared.fastly.steamstatic.com/store_item_assets/steam/apps/1850050/ss_e3904457c6e382548706c0ed23ed32efdd67d850.1920x1080.jpg?t=1746720392)

During this project, I worked extensively on AI and gameplay features to bring the Xenomorphs to life. These span reactive perception and navigation, melee combat, flexible behavioral states, and a dynamic spawning system that leverages actor pooling and simulation to reduce unnecessary computation.

I also had the opportunity to learn and develop engine tools and automated pipelines to support testing the proprietary navigation system these enemies used. These tools were crucial to reducing our QA effort by eliminating the need for manual path validation as new assets and geometries were added/swapped out. This would have been a continuous process that would require constant effort to maintain playability otherwise. <br />
